======================================================================
              DISCORD SOUND THEME SWITCHER (C++)
======================================================================

Программа позволяет в один клик переключать любые звуковые режимы Discord:
  [1] Классический (Default) - возвращает дефолтные звуки (отключает Хэллоуин)
  [2] Новогодний (Winter Holiday) - полный зимний пак (бубенцы, зимний войс)
  [3] Новогодний Snowsgiving - зимний пак + праздничный рингтон Snowsgiving
  [4] Новогодний Snow Halation - зимний пак + секретная мемная пасхалка (1 к 1000)
  [5] Хэллоуин (Halloween) - жуткие хэллоуинские звуки
  [6] Ретро 8-Бит (Retro Beat) - 8-битное сообщение + битовый рингтон
  [7] Lo-Fi Chill - расслабляющие звуки
  [8] Ducky (Уточка) - кряканье на сообщения
  [9] Bubble (Bop) - всплывающие пузырьки
  [0] Сбросить все патчи - возвращает чистый заводской Discord

КАК ПОЛЬЗОВАТЬСЯ:
1. Запустите DiscordSoundSwitcher.exe
2. Выберите нужный номер (например, 2 для Новогоднего)
3. Нажмите Enter, чтобы перезапустить Discord с новым звуковым пакетом

КАК ЭТО РАБОТАЕТ:
Программа устанавливает легковесный перехватчик в загрузчик Discord
(%APPDATA%\discord\sound_hook.js). При воспроизведении звуков Discord
автоматически перенаправляет аудиозапросы к выбранному набору звуков.
Никакие важные системные файлы не повреждаются.
В любой момент можно нажать [0] для полного удаления всех хуков.
